# BlackJack

Aplicación móvil de BlackJack desarrollada como trabajo práctico/primer parcial de la materia **Aplicaciones Móviles** de la carrera **Analista de Sistemas**.

## Funcionalidades

- Ingreso del nombre del jugador.
- Partida de BlackJack contra el crupier.
- Pedir cartas y plantarse.
- Cálculo automático de puntos.
- Manejo del As como 1 u 11.
- Carta oculta del crupier durante el turno del jugador.
- Finalización automática al llegar a 21.
- Pantalla de resultado con puntajes.
- Estadísticas de la sesión.
- Navegación entre las distintas pantallas de la aplicación.

## Tecnologías

- Android Studio
- Java
- XML
- Android Views
